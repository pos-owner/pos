# AGENTS.md

pOS is a React PWA plus a Hono API that runs on Cloudflare. One Worker serves the static assets in `dist/` and handles `/api/*`. The data and photos live in D1 (no R2), the daily job runs on Cron plus Queues, and meter photos are read by Workers AI. Full docs are in `docs/`, starting at `docs/README.md`.

## Key directories
- `src/`: the React app (screens grouped by role: owner, staff, tenant, shared, tools).
- `worker/index.ts`: Workers entry (fetch, scheduled, queue). `worker/pages-entry.ts`: Pages entry (fetch only, migrates its own database).
- `worker/server/`: route files (`*Routes.ts`), plus `core/` (bindings, env, auth, secure headers, migrate) and `domain/` (business logic).
- `worker/db/schema.ts`: the Drizzle schema and the source of truth for tables.
- `shared/`: code used by both browser and Worker (PDF drawing, login key).
- `drizzle/` → `migrations/` → `worker/migrations.generated.ts`: all three are generated by `scripts/migrations.mjs`. Never edit them by hand.
- `cloudflare/cron-worker/`: the companion cron Worker, needed only for the Pages deployment.
- `scripts/`: `dev-api`, `smoke`, `cf-setup`, `cf-backup`, `cf-reset-link`, `pages-bundle`, `migrations`.
- Every package the code imports must be in `package.json`: `tests/unit/dependencies.test.ts` fails otherwise.

## Conventions
- Imports use explicit `.ts` extensions. Do not use `enum` or `namespace`: Node runs the tests with type stripping.
- Read bindings with `bindings()` and settings with `env("NAME")`. Never pass `env` through domain code.
- D1 has no interactive transactions. Use guarded single statements, `db.batch`, or triggers.
- Keep migrations additive, and never edit a migration that has already been deployed.
- Security headers for API responses live in `worker/server/core/secure.ts`. Headers for static files live in `public/_headers`.
- Secrets go in `wrangler secret`, never in `wrangler.jsonc`.

## Commands
`npm run dev:api` + `npm run dev`, `npm test`, `npm run check`, `npm run verify`, `npm run smoke`, `npm run deploy`.

## Ongoing work
See `PLAN.md` for the upgrade milestones (done and remaining). Display preferences live in `src/lib/display.ts` (data attributes on `<html>`, CSS at the end of `src/styles/global.css`); dark-mode rules must cover both `@media (prefers-color-scheme: dark)` with `:root:not([data-theme="light"])` and `:root[data-theme="dark"]`. The receipt slip is drawn in `shared/pdf/receipt.ts`; the shared logo is `drawLogo` in `shared/pdf/writer.ts`.

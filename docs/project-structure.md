# Project structure

```
.
├── src/                        React PWA (Vite)
│   ├── main.tsx, App.tsx       entry, role-based routing (owner / staff / tenant)
│   ├── screens/
│   │   ├── auth/               welcome, sign in/up, onboarding, join by invite, reset password
│   │   ├── owner/              home, rent, tenants, properties, settlements, invites, backup, …
│   │   ├── staff/              today, units
│   │   ├── tenant/             home, history, lease, profile, pay sheet
│   │   ├── shared/             requests, expenses, notifications, outbox, settings, scan unit
│   │   ├── tools/              receipts, meters, automations, reports, statements, QR codes
│   │   │   └── locked/         preview screens for tools switched off in src/lib/features.ts
│   │   └── public/             receipt verification (no login)
│   ├── components/             shared UI kit, icons, bell, install card, photo picker
│   ├── lib/                    API client, auth, i18n, offline outbox, push, PDF, formatting
│   ├── i18n/hi.json            Hindi strings (English is the source text)
│   └── styles/                 global + per-area CSS
│
├── worker/                     Cloudflare Worker
│   ├── index.ts                Workers entry: fetch (/api/*), scheduled (cron), queue
│   ├── pages-entry.ts          Pages entry: fetch only, self-migrating D1, setup checklist
│   ├── migrations.generated.ts migrations/*.sql embedded for Pages (generated, do not edit)
│   ├── db/
│   │   ├── schema.ts           Drizzle schema for D1 — the source of truth for tables
│   │   └── index.ts            Drizzle on D1, 100-parameter workaround, `db` proxy
│   └── server/
│       ├── routes.ts           Hono app: mounts every route group
│       ├── *Routes.ts          auth, payments, billing, leases, documents, exports, notifications, tools
│       ├── core/               bindings, env, auth, access rules, rate limits, storage, mail, web push,
│       │                       migrations runner, response hardening (secure.ts), utilities
│       ├── domain/             business logic: charges, payments, allocation, fees, leases, settlements,
│       │                       meters, statements, reports, notifications, automations, seed data
│       └── pdf/                JSON models for receipts and agreements
│
├── shared/                     code used by both browser and Worker
│   ├── loginKey.ts
│   └── pdf/                    PDF writer, QR codes, receipt/agreement/statement/report layouts
│
├── drizzle/                    Drizzle Kit output: <timestamp>_<name>/migration.sql + snapshot.json
├── migrations/                 flat copies Wrangler applies (generated by scripts/migrations.mjs)
├── drizzle.d1.config.ts        Drizzle Kit config (D1 / SQLite)
│
├── public/                     copied as-is into dist/
│   ├── _headers                cache + security headers (Workers assets and Pages both read it)
│   ├── robots.txt              sign-in page indexable, /api/ not
│   ├── push-sw.js              Web Push handlers imported by the generated service worker
│   ├── icons/, img/            app icons, link-preview image, welcome illustration
│   └── favicon.ico
│
├── cloudflare/
│   └── cron-worker/            companion daily-cron Worker for the Pages deployment
│       ├── index.js
│       └── wrangler.jsonc
│
├── scripts/
│   ├── migrations.mjs          drizzle/ → migrations/ → worker/migrations.generated.ts
│   ├── dev-api.mjs             `npm run dev:api`: wrangler dev without the AI binding (no login), local D1 + R2
│   ├── smoke.mjs               `npm run smoke`: checks a running pOS (health incl. D1, static files, headers)
│   ├── cf-setup.mjs            creates/finds D1 (apac by default), R2, queue; writes database_id
│   ├── cf-backup.mjs           exports D1 to backups/
│   ├── cf-reset-link.mjs       emergency password-reset link straight in D1
│   └── pages-bundle.mjs        builds pos-upload.zip for Pages drag-and-drop
│
├── tests/
│   ├── unit/                   pure logic (rent, billing, allocation, access, i18n, migrations…)
│   ├── api/                    real Hono API against Miniflare D1 + R2
│   └── helpers/                test app and workspace builders
│
├── docs/                       this documentation
├── .github/workflows/cloudflare.yml   check on PRs, deploy on main
├── wrangler.jsonc              the Worker: assets, bindings, cron, vars
├── vite.config.ts              PWA build, /api dev proxy
├── tsconfig.json               one type-check for everything
├── .dev.vars.example           local secrets template for wrangler dev
└── package.json
```

## Generated files

Never edit these by hand; re-run the script instead.

| File | Made by |
| --- | --- |
| `drizzle/*/migration.sql`, `snapshot.json` | `npm run db:generate` (Drizzle Kit) |
| `migrations/*.sql` | `npm run db:sync` |
| `worker/migrations.generated.ts` | `npm run db:sync` |
| `dist/` | `npm run build` |
| `pos-upload.zip`, `dist/_worker.js`, `dist/_routes.json` | `npm run pages:bundle` |
| `.wrangler/` | Wrangler (local D1/R2 state, dry-run bundles) |
